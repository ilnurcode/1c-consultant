# 1C-Consultant 4.3.0

Версия 4.3.0 объединяет консольное приложение, MCP и стандартный OData-интерфейс
1С в одном безопасном read-only контракте.

## Новое

- раздел `Данные 1С (OData)` в интерактивном меню;
- настройка адреса и скрытых учётных данных на текущий запуск без записи на диск;
- CLI-команды `odata status`, `odata entities`, `odata query`;
- MCP-инструменты `get_odata_status`, `list_odata_entities`, `query_odata`;
- конфигурация через локальные переменные `ONEC_ODATA_*` без сохранения пароля;
- ограничение выборки 1000 строк и отсутствие операций создания, изменения и удаления;
- тесты OData v3 и современного JSON-формата, проверки безопасных имён и URL.

## Совместимость

Канонический Python workflow, граф и lifecycle проектов не изменены. MCP остаётся
дополнительным интерфейсом. Для удалённой проверки OData требуется опубликованный
`standard.odata` и пользователь 1С с правами только на необходимые данные.

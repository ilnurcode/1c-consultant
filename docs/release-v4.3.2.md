# 1C-Consultant 4.3.2

Добавлен раздел «Подключения к базам 1С». В нём сохраняются только название и адрес веб-клиента; адрес OData определяется автоматически. Логин и пароль вводятся консультантом на текущий сеанс и не сохраняются.

Раздел «Автоматизация 1С» использует уже выбранную базу и не содержит учётных данных или фиксированного адреса тестовой базы.

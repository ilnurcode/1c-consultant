# 1C-Consultant 4.3.1

Добавлен отдельный раздел «Автоматизация 1С (MCP + OData)».

- Playwright MCP используется в Codex для действий в веб-клиенте 1С.
- OData остаётся безопасным read-only каналом для проверки данных.
- Раздел показывает готовность обоих компонентов, открывает 1С:ERP, выводит сценарий для Codex и позволяет проверить заказ по номеру через OData.
- Пункт «Данные 1С (OData)» сохранён для самостоятельного просмотра сущностей и данных без управления веб-интерфейсом.

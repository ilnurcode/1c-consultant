# Демонстрационное расширение 1С:Предприятие (с дефектами v8std и уязвимостями)

Данное расширение подготовлено для наглядной демонстрации возможностей **1C-Consultant**:
1. Статический анализ и аудит безопасности кода 1С.
2. Проверка соответствия стандартам разработки **v8std** и ИТС.
3. Генерация и проведение веб-тестов **Playwright**.

## Заложенные дефекты для проверки:

| Правило | Файл | Описание ошибки |
|---|---|---|
| **`LCK001`** | `Documents/ЗаказКлиента/.../ObjectModule.bsl:7` | Запись движений в `ОбработкаПроведения` без явной `БлокировкаДанных` |
| **`SEC001`** | `Documents/ЗаказКлиента/.../ObjectModule.bsl:34` | Опасный вызов `Выполнить()` с динамической строкой (RCE) |
| **`SEC002`** | `Documents/ЗаказКлиента/.../ObjectModule.bsl:19` | Инъекция в текст запроса через конкатенацию `+ КодТовара` |
| **`SEC003`** | `CommonModules/ИнтеграцияСлужебный/.../Module.bsl:7` | Неконтролируемый `УстановитьПривилегированныйРежим(Истина)` |
| **`SEC004`** | `Documents/ЗаказКлиента/.../ObjectModule.bsl:37` | Хардкод пароля/токена шлюза `SecretTokenKey_2026` |
| **`SEC005`** | `CommonModules/ИнтеграцияСлужебный/.../Module.bsl:10` | Вызов `КомандаСистемы("curl ...")` с непроверенным параметром |
| **`PERF001`** | `CommonModules/ИнтеграцияСлужебный/.../Module.bsl:13` | Выполнение запроса внутри цикла (антипаттерн N+1) |
| **`PERF002`** | `Documents/ЗаказКлиента/.../Module.bsl:4` | Серверный вызов `&НаСервере` внутри цикла на клиенте |
| **`STD002`** | `Documents/ЗаказКлиента/.../Module.bsl:17` | Пустой блок `Исключение ... КонецПопытки` |
| **`v8std:comment-api`** | `CommonModules/ИнтеграцияСлужебный/.../Module.bsl:5` | Экспортная процедура без документирующей шапки |
| **`v8std:naming`** | `Documents/ЗаказКлиента/.../Module.bsl:11` | Однобуквенная переменная `с = 100;` |
| **`v8std:virtual-tables-params`** | `Documents/ЗаказКлиента/.../ObjectModule.bsl:25` | Виртуальная таблица `.Остатки()` без параметров с `ГДЕ` |
| **`v8std:unconditional-server-context`** | `Documents/ЗаказКлиента/.../Module.bsl:24` | `&НаСервере` вместо `&НаСервереБезКонтекста` |

## Быстрый запуск проверки:

```bash
# Через CLI:
consultant.cmd scan ./demo_extension

# В формате SARIF для CI/CD:
consultant.cmd scan ./demo_extension --format sarif

# Через Web-интерфейс:
consultant.cmd web
# Во вкладке «Аудит кода» укажите путь: ./demo_extension
```
